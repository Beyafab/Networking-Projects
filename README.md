# 🌐 CCNA 200-301 Networking Labs & Projects

Welcome to my networking portfolio! This repository contains a collection of Cisco CCNA 200-301 labs, topologies, and configurations. These projects demonstrate practical skills in routing, switching, network security, and troubleshooting using Cisco IOS and Packet Tracer.

## 🛠️ Tools & Technologies Used
*   **Simulation:** Cisco Packet Tracer / GNS3
*   **Operating Systems:** Cisco IOS (v15.x / v16.x)
*   **Protocols:** IPv4, IPv6, Static Routing, OSPF, EIGRP, VLANs, STP, DHCP, NAT, ACLs.
